# Countdown action package (ROS 2 Humble)

This package generates `custom_action_pkg/action/CountDown` and installs two
Python nodes. The node modules live in `custom_action_nodes` to avoid conflicting
with the Python package generated by `rosidl`.

## Build

```bash
source /opt/ros/humble/setup.bash
cd /home/nipun/ros2_ws
colcon build --packages-select custom_action_pkg --symlink-install --cmake-clean-cache
source /home/nipun/ros2_ws/install/setup.bash
```

If dependencies are missing, install them before building:

```bash
rosdep install --from-paths /home/nipun/ros2_ws/custom_action_pkg --ignore-src -r -y
```

## Run both nodes

```bash
source /opt/ros/humble/setup.bash
source /home/nipun/ros2_ws/install/setup.bash
ros2 launch custom_action_pkg count_down.launch.py target:=5
```

The client prints feedback from 5 through 0, prints `Final result: Done!`, and
exits. The server stays running until Ctrl+C. The default target is 10.

## Run separately

Terminal 1:

```bash
source /opt/ros/humble/setup.bash
source /home/nipun/ros2_ws/install/setup.bash
ros2 run custom_action_pkg action_server
```

Terminal 2:

```bash
source /opt/ros/humble/setup.bash
source /home/nipun/ros2_ws/install/setup.bash
ros2 run custom_action_pkg action_client --ros-args -p target:=5
```

Alternatively, send a goal directly from Terminal 2:

```bash
ros2 action send_goal /count_down custom_action_pkg/action/CountDown '{target: 5}' --feedback
```

Targets must be nonnegative int32 values. The server supports action cancellation.
The Python client waits up to 10 seconds for the server to become available.

## Test

```bash
source /opt/ros/humble/setup.bash
source /home/nipun/ros2_ws/install/setup.bash
cd /home/nipun/ros2_ws
colcon test --packages-select custom_action_pkg --event-handlers console_direct+
colcon test-result --test-result-base /home/nipun/ros2_ws/build/custom_action_pkg --verbose
```

Tests cover feedback/results, a zero target, negative-goal rejection, cancellation,
and client completion. The existing template copyright test remains skipped.
